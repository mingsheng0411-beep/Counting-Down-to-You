# 在见面之前

**Counting Down to You** · 给相隔两地的人的一个小空间：在一张会随昼夜变化的地图上，一起倒数下次见面，看见彼此的距离、天气和心情，存放共同的回忆和计划。

A small shared space for two people far apart: count down to the next time you meet on a map that follows day and night, see the distance, weather and mood between you, and keep your shared memories and plans.

> 本文件是项目的核心大纲。方向、范围或版本计划有变化时，先改这里。
>
> 曾用名：Faraway Together、献给亲爱的你。项目文件夹仍叫 `faraway-together`，只是本机上的名字。

## 一句话定位

任何相隔两地的两个人（恋人、家人、朋友）都可以拥有一个只属于彼此的页面。不限国家，不限语言。

## 核心概念

- **空间（Space）**：一对情侣共享的私密页面，所有数据都挂在空间上。
- **配对**：一方注册后生成邀请链接，另一方点开加入，两人进入同一个空间。
- **默认私密**：空间内容只有两人可见，除非他们主动分享。

## 功能模块

### 1. 倒计时
- 下次见面倒计时（天 / 时 / 分 / 秒），放在地图右上角
- 在一起 / 认识了多少天
- 双方当地时间并排显示，提示对方是白天还是深夜
- 纪念日提醒（后续）

### 2. 距离可视化
- 一张占满整个屏幕的平面地图，标出两人所在位置和之间的航线，显示实际距离
- 地图上有两个输入框，直接输入彼此所在的城市或地区；选好后地图平滑移动并缩放到合适的范围
- 两地的实时天气画在各自位置上方：线稿风格的小太阳、月亮、云，下雨和下雪是流动的线条动画
- 打开时的动画：地球转过来、铺开成平面地图，再画出航线，之后小飞机沿航线往返
- 距离直接写在地图上航线的正下方；地图下面只留时差和直飞时长两格
- 见面时距离归零的动画（后续）

### 地点介绍
- 地图上有十几个经典城市的小圆点（东京、首尔、上海、巴黎、纽约等），点开是一张侧边卡片：当地时间、天气、到两人各自的距离，以及一段简介和图片
- 两人各自所在的城市同样可以点开（点地图上的城市标签）
- 经典城市的圆点会自动避开两人城市的标签、天气图标和航线，免得挤在一起
- 地图可以滚轮缩放、拖动平移，能放大到街区级别，右侧有放大缩小按钮；缩到最小后继续滚动才会滚动页面；点重播按钮回到自动取景
- 简介来自维基百科，优先用当前语言，没有再用英文；维基百科打不开时（中国大陆是常态），中国的主要城市改用项目里自己写的简短介绍

### 心情和航班
- 每个人可以设一个心情：一个表情加一句话，显示在自己的时间卡片和地图标签上
- 航班导入：把订票短信或行程单的文字粘贴进去，自动识别航班号、出发到达地、日期和时间，可以手动修改；保存后见面日期设为到达那天
- 航班识别是从文字里找规律，不是联网查询；按航班号查实时航班需要付费的航班数据服务，留到后面版本

### 我们的计划
- 回忆下面的一栏：写下想一起做的事，做完勾掉，右上角显示完成了几件

### 3. 回忆
- 时间线：照片、日期、一句话
- 地图视图：把回忆钉在发生的地点
- 两人都可以添加和编辑

### 4. 一起计划（后续版本）
- 共享旅行计划：目的地、日期、行程清单、预算
- AI 生成行程建议
- 酒店、机票跳转到携程 / Trip.com 等平台

## 版本路线

| 版本 | 内容 | 完成标准 |
|---|---|---|
| V0 原型 | 纯前端情侣页面：倒计时、双方时间、距离地图、回忆时间线；数据存在浏览器本地 | 打开就能看到完整效果，视觉和体验定稿 |
| V1 可用产品 | 注册登录、邀请配对、照片上传、云端存储、隐私权限、多语言 | 一对陌生情侣可以独立完成注册、配对并使用 |
| V2 一起计划 | 共享旅行计划，两人可同时编辑 | 能完整记录一次见面旅行的安排 |
| V3 外部接入 | AI 行程建议，酒店 / 机票平台跳转 | 从计划页能一步跳到可预订的结果 |

当前阶段：**V0 原型已完成，等待体验和调整**

## 运行方式

需要 Node.js（已安装 LTS 版本）。在项目文件夹里：

```bash
npm install
```

```bash
npm run dev
```

然后打开 http://localhost:3000 。其他命令：`npm run build`（生产构建）、`npm run lint`（代码检查）。

## 演示视频

- `/zh/demo` 是一个自动播放的 23 秒演示页（两个人叫 A 和 B），打开就按脚本快速播放，用来录屏。
- 录成 mp4：先 `npm run build`，再 `npx next start -p 3100`，然后 `node scripts/record-demo.mjs`。脚本用本机的 Edge 打开半速版（`/zh/demo/record`），先播两遍预热地图，第三遍逐帧抓取，再用 FFmpeg 加速回正常速度，合成 2560×1440、60 帧的 mp4。半速抓帧是为了流畅：边播边抓会拖慢浏览器，放慢一倍就能多抓一倍的画面。需要已安装 FFmpeg。
- 演示里 A 从中国各地出发，B 在国外；字幕文案在 `features/demo/demo-reel.tsx` 顶部。
- 成片放在 `demo/` 文件夹，没有声音，音乐自己配。

## 架构

### 技术栈

| 部分 | 选择 | 说明 |
|---|---|---|
| 框架 | Next.js 16（App Router）+ React 19 + TypeScript | 页面、路由、以后的服务端接口都在一个项目里 |
| 样式 | Tailwind CSS 4 | 颜色和字体统一定义在 `src/app/globals.css` 的 `@theme` 里 |
| 地图 | MapLibre GL（开源地图引擎） | 白天用 OpenFreeMap 的矢量地图（OpenStreetMap 数据），样式在 `map-style.ts` 里自己定义成淡蓝白、很少地名；夜晚叠一层 NASA Black Marble 夜间灯光图。两者都从国外服务加载，中国大陆可能慢或打不开 |
| 本地存储 | IndexedDB（idb-keyval） | V0 的数据和照片都存在浏览器里 |
| 地点和天气 | Open-Meteo（免费，无需账号） | 地点搜索会把输入的文字发给它，天气查询会把城市坐标发给它；连不上时仍可用内置城市，只是没有天气 |
| 地点简介 | 维基百科摘要接口 | 只发送地名；会核对条目坐标，避免同名的别处；连不上时用 `domain/place-notes.ts` 里自写的介绍 |
| 多语言 | 路由前缀 `/zh`、`/en` + 字典文件 | 按浏览器语言自动跳转 |
| 字体 | Inter（随项目打包） | 不请求 Google Fonts；中文用系统字体 |

V1 计划加入（开始前再确认）：Supabase（账号、数据库、照片存储、行级权限）、邮箱和第三方登录、Vercel 部署。

### 分层

代码分四层，依赖方向只能从上往下：

```
app/        路由和页面，只负责把功能模块拼起来
features/   功能模块：倒计时、时钟、距离、回忆、设置、空间
data/       数据访问：空间存储、天气、地点搜索三个接口和各自的实现
domain/     数据模型和纯计算：类型、距离、时间、城市
```

- `domain/` 不依赖 React 和浏览器，可以原样用在服务端。
- `features/` 只通过 `useSpace()` 读写数据，不直接接触存储。
- 天气（`weather-provider.ts`）和地点搜索（`place-search.ts`）也是接口，换服务商只改 `data/index.ts`。
- `data/space-repository.ts` 是界面和存储之间唯一的接口。V0 用 IndexedDB 实现；V1 新增一个云端实现，只需要改 `data/index.ts` 一处，功能模块不用动。

### 约定

- 加一个新功能：在 `features/` 下建一个文件夹，在 `space-view.tsx` 里挂上。
- 加一种语言：在 `i18n/config.ts` 的 `locales` 里加一项，再加一个字典文件。
- 界面文字一律写在字典里，不写死在组件中。
- 需要用户填写的地方，占位文字统一写"等待输入"；还没填的心情、航班、见面日子也这样标注。
- 颜色只有三种：白、墨黑（`ink`）、海的淡蓝（`sea`，#c8ddfc）。所有蓝色都用 `sea`；文字、航线、图标线稿用 `ink`。
- 见面只精确到日，存成那一天零点的时刻。
- 日期一律用年、月、日三个数字下拉框（`DateSelect`），不用浏览器自带的日期控件。
- 地图上的航线是屏幕上的一段圆弧，只为好看；距离数字仍按地球表面的最短路线计算。

### V0 的已知限制

- 数据只在当前浏览器里，换设备或清除浏览器数据就没有了，两个人也还不能共享。
- 地点搜索到城市和地区一级，不支持门牌号这样的详细地址。
- 示例空间里改地点、心情、航班都只是预览，不会保存。
- 地图有两种样子，轮流出现：简洁的淡蓝白地图（每次打开先显示它）和带昼夜的卫星图。目前每 60 秒自动切换一次（`world-map.tsx` 里的 `LOOK_MS`，暂定值），也可以点地图右侧半明半暗的圆形按钮手动切换。
- 切到卫星图后，镜头会依次飞到两人各自的城市并放大，切回简洁地图时回到两地同框的视野；有人拖动或滚轮缩放地图时，本轮的自动飞行就停止。
- 卫星图里白天那半边是 NASA 的白天卫星图，夜晚那半边是夜间灯光图，交界处有一条日出日落的暖色光带。
- 两人地点下方各浮着一张照片，取自回忆里的照片，按时间从新到旧分给两边，每 8 秒换一张。
- 地图按真实时间显示昼夜：两张地图叠在一起，白天图在下，NASA 夜景图在上；夜景图用一张按太阳位置算出的遮罩裁到夜晚那半边，交界处是渐变的暮色，每分钟更新一次。
- 航线、飞机、标记、天气图标画在最上层的一张透明画布上，位置由地图引擎换算。
- 地图引擎有一个单独的工作线程文件，安装依赖后由 `scripts/copy-map-worker.mjs` 复制到 `public/vendor/`（已加入 .gitignore）。
- 示例空间是只读的，设置好自己的空间后才能添加回忆。

## 原则

- 先好看、先打动人，再堆功能
- 视觉风格：海的淡蓝和白色，iOS 26 液态玻璃质感（半透明、强模糊、高光描边，用 `glass` 样式类），大号粗体黑色数字，线稿图标
- 隐私优先：情侣的照片和文字默认不公开
- 每个版本都要是一个能独立使用的东西
